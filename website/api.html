API của Mướp Agents server

Mọi chức năng của ứng dụng đi qua server Rust trên cổng 8787, qua REST (JSON) và Socket.IO v4. Bạn có thể dùng chung các endpoint này để viết script, tích hợp, hoặc làm client riêng.

Đổi địa chỉ để mọi ví dụ curl bên dưới dùng đúng máy của bạn. Lưu trong trình duyệt này. Chạy curl http://<ip>:8787/api/ping để kiểm tra kết nối.
Định dạng

JSON, khóa camelCase. Nội dung nhị phân ở một số endpoint file và ảnh.

Xác thực

Không có. Chỉ dùng trong LAN hoặc VPN tin cậy.

Kích thước body

Tối đa 64MB (đủ cho ảnh base64).
